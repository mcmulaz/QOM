Inside of the Dynamic Polarizability file there is fit_atomic_polarizability.py. 
Download this file into a specific folder and then within that same folder use a notebok of choice (e.g. Jupyter)
and type in a cell 'run fit_atomic_polarizability.py --output-dir fit_output --show' which will show you the values of lambda, Omega, and the associated plots. 
Information on units and extraction of data is contained within the code itself.
